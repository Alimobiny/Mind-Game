# نسخهٔ دسکتاپ (فایل exe) — راهنمای فارسی 🖥️

## exe کجاست؟

بعد از `npm run desktop:build` دو فایل در پوشهٔ `release/` ساخته می‌شود:

| فایل | حجم حدودی | کاربرد |
|---|---|---|
| **`Cognitive Training Lab 0.1.0.exe`** | ~۱۱۲ MB | **پرتابل** — دوبارکلیک و بازی؛ بدون نصب، قابل کپی به هر ویندوز ۶۴بیتی |
| `Cognitive Training Lab Setup 0.1.0.exe` | ~۱۲۳ MB | نصب‌شونده — میانبر در منوی استارت نصب می‌کند |

## استفاده

۱. روی exe پرتابل دوبارکلیک کنید — پنجرهٔ بازی باز می‌شود (بدون مرورگر، بدون Node، کاملاً آفلاین).
۲. اجرای دوم: به‌جای پنجرهٔ جدید، همان پنجرهٔ باز جلو می‌آید.
۳. بستن = بستن پنجره؛ داده‌ها ذخیره می‌مانند.

## داده‌ها کجاست؟

داده‌های نسخهٔ exe در پروفایل برنامه ذخیره می‌شود: `%APPDATA%\Cognitive Training Lab` — **جدا از دادهٔ مرورگر**. برای انتقال پیشرفت بین نسخهٔ مرورگر و نسخهٔ exe، از صفحهٔ «گزارش‌ها» → خروجی/ورودی JSON استفاده کنید (هر دو نسخه یک قالب پشتیبان دارند).

## نکته‌ها

- **اینترنت لازم نیست** — کل بازی داخل exe بسته‌بندی شده است.
- **آنتی‌ویروس**: exe امضای دیجیتال ندارد (ساختهٔ شخصی)؛ بعضی آنتی‌ویروس‌ها هشدار اولیه می‌دهند — «اجازهٔ اجرا» بدهید.
- **بازسازی**: در مخزن `npm run desktop:build` (خودش آیکون می‌سازد + بیلد وب با مسیر نسبی + electron-builder). برای تست سریع بدون بسته‌بندی: `npm run icons` + `DEPLOY_BASE=./ npx vite build` + `npm run desktop`.
- `start-game.bat` هنوز برای توسعه سر جای خودش است — exe برای استفادهٔ روزمره است.
- داخل exe روتر hash است (`#/play/...`) — کاملاً طبیعی و بی‌اثر در استفاده.

## معماری (برای توسعه‌دهنده)

- `electron/main.cjs` — فرایند اصلی: پنجره، قفل تک‌نمونه، بارگذاری `dist/index.html` با file://؛ پرچم `--smoke` برای راستی‌آزمایی خودکار (۳ث → اسکرین‌شات در `test-results/electron-smoke.png` → خروج ۰).
- `src/app/router.tsx` روی پروتکل `file:` به `createHashRouter` سوییچ می‌کند (وب دست‌نخورده).
- بیلد دسکتاپ با `DEPLOY_BASE=./` مسیرهای نسبی می‌سازد.
- آیکون: `scripts/make-icons.mjs` با sharp از `public/icons/icon.svg` → `build/icon.png`؛ electron-builder خودش ico می‌سازد.
