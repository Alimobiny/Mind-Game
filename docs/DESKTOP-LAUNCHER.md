# راهنمای اجرای دسکتاپ — دوبارکلیک و بازی 🎮

`start-game.bat` در ریشهٔ مخزن، ساده‌ترین راه اجرای آفلاین بازی روی ویندوز است.

## پیش‌نیاز (فقط یک بار)

- **Node.js** نصب باشد — نسخهٔ LTS از [nodejs.org](https://nodejs.org)
- یک بار مخزن را روی کامپیوتر داشته باشید (clone یا دانلود ZIP)

## اجرا

۱. روی **`start-game.bat`** دوبارکلیک کنید.
۲. اولین اجرا: وابستگی‌ها خودکار نصب می‌شوند (~۱ دقیقه، نیاز به اینترنت).
۳. سرور در یک **پنجرهٔ کمینه** با عنوان `Mind Game Server` بالا می‌آید و بازی در مرورگر پیش‌فرض روی `http://localhost:5173` باز می‌شود.

## توقف

- پنجرهٔ کمینهٔ **Mind Game Server** را در نوار وظیفه ببندید. (یا داخلش `Ctrl+C`)

## نکته‌ها

- **اگر بازی از قبل روشن باشد:** دوبارکلیک دوباره فقط مرورگر را روی همان نمونهٔ در حال اجرا باز می‌کند.
- **پورت ۵۱۷۳:** اگر برنامهٔ دیگری این پورت را گرفته باشد، سرور بالا نمی‌آید — آن برنامه را ببندید.
- **جایگزین دستی:** در ترمینال `npm run dev` و سپس مرورگر روی `http://localhost:5173`.
- **داده‌های شما کجاست؟** داده‌ها در IndexedDB همان مرورگر و همان آدرس ذخیره می‌شوند. دادهٔ نسخهٔ `localhost` با دادهٔ نسخهٔ آنلاین ([GitHub Pages](https://alimobiny.github.io/Mind-Game/)) **جدا** است — برای جابه‌جایی از خروجی JSON (صفحهٔ گزارش‌ها → Export/Import) استفاده کنید.
