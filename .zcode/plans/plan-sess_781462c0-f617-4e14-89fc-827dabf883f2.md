# پلن موج سوم — ۴ بازی جدید + دشواری تطبیقی + گزارش پیشرفت + Export/Import

## Context

کاربر موج سوم را تأیید کرد با این تصمیمات: حد نصاب = **دقت ≥ ۸۰٪** | کاهش سطح = **بله** (روزِ ضعیف زیر ۵۰٪ → یک سطح کم) | بازی‌ها = **Word Memory، Syllable Counting، Sequence Logic، Pattern Completion** | انتشار گیت‌هاب = **بعد از موج سوم**، ولی نکته کلیدی کاربر: **داده‌ها و سیر پیشرفت باید قابل بازیابی و منتقل‌پذیر باشند** → Export/Import JSON در همین موج.

## بخش ۱ — دشواری تطبیقی (Rule-Based، خودم می‌سازم قبل از پرتاب ایجنت‌ها)

**قوانین (به تفصیل):**
- جلسه «موفق» = completed با `summary.accuracy ≥ 80` در **سطح پیشنهادیِ آن زمان**
- روز «ضعیف» = روزِ دارای تمرین که بهترین دقتش `< 50` است (در سطح پیشنهادی)
- **افزایش:** ۳ روز تقویمی متوالی که هر کدام ≥۱ جلسه موفق دارند → سطح +۱ (سقف ۵)
- **کاهش:** روز ضعیف → سطح −۱ (کف ۱) و شکست رکورد
- روز بی‌تمرین → فقط رکورد می‌شکند (سطح ثابت)
- جلسات با سطحِ دستی انتخابی، در ارزیابی لحاظ نمی‌شوند (فقط پیشنهادی سیستم)

**پیاده‌سازی — تابع خالص بدون نیاز به migration:**
- فایل جدید `src/core/difficulty/adaptive-difficulty.ts`: `computeAdaptiveDifficulty(sessions: SessionRecord[], todayIso: string)` — شبیه‌سازی قطعی روی تاریخچه مرتب (گروه‌بندی روز با تاریخ local). خروجی: `recommendedLevel`، `streakQualifyingDays`، `streakNeededDays=3`، `levelHistory` (تغییرات سطح با تاریخ — Traceability)، `lastPlayedDate`، `totalSessions`
- **بدون استور جدید** — همه از SessionRecordهای موجود مشتق می‌شود (وفادار به اصل «داده خام مبنای تصمیم»)
- تست واحد کامل: افزایش/کاهش/شکست رکورد با روز جاافتاده/سقف و کف/جلسات دستی نادیده/روز مرزی «امروز»

## بخش ۲ — UI پیشرفت و دشواری (خودم، همزمان با کار ایجنت‌ها)

- **ExercisePage**: سطح پیشنهادی به‌صورت پیش‌فرض انتخاب + badge «سطح پیشنهادی سیستم» + نمایش رکورد (مثل «رکورد ۲ از ۳ روز»)؛ تغییر دستی همچنان ممکن با برچسب «انتخاب دستی»
- **Results بعد از جلسه**: پاس‌شدن حد نصاب (≥۸۰٪) + وضعیت رکورد فعلی
- **HomePage** کارت هر بازی: سطح فعلی · تعداد جلسات · رکورد
- **ReportsPage**: برای هر بازی — تعداد کل جلسات، آخرین روز انجام، جدول جلسات اخیر (تاریخ/سطح/دقت) + تایم‌لاین تغییرات سطح (از levelHistory)

## بخش ۳ — Export/Import (پاسخ به نکته بازیابی/انتقال داده کاربر)

- فایل جدید `src/data/export-import.ts`: Export = همه `exercise_sessions` + `trial_events` → فایل JSON (شامل schemaVersion/exportedAt/appVersion) با دانلود Blob؛ Import = اعتبارسنجی ساختار + upsert بر اساس id (idempotent) + گزارش تعداد رکوردهای ادغام‌شده — هیچ داده‌ای بدون رونویسی حذف نمی‌شود
- UI در ReportsPage: دو دکمه «خروجی پشتیبان (JSON)» و «بازیابی از فایل» + پیام نتیجه
- تست integration: export → پاک‌سازی → import → داده یکسان

## بخش ۴ — ۴ بازی موج سوم (۴ ایجنت موازی، الگوی موفق موج دوم)

هر ایجنت فقط در پوشه خودش: engine خالص + `configForDifficulty` + تست قطعی + UI + CSS (قید «هیچ فایلی خارج از پوشه خودت»):

1. **Word Memory** (`src/modules/verbal-auditory/games/word-memory/` — پوشه حوزه زبانی جدید): فاز مطالعه N کلمه فارسی یکی‌یکی → فاز بازیابی: شبکه 2N کلمه (N دیده‌شده + N حواس‌پرتی) → انتخاب N مورد → تأیید. Trial = یک بلوک؛ ۶ بلوک؛ متریک‌های hits/falseAlarms/misses. بانک ~۶۰ کلمه رایج با contentVersion. دشواری = N و سرعت نمایش.
2. **Syllable Counting** (`.../syllable-counting/`): نمایش جمله فارسی → ورود تعداد هجا با keypad عددی. **بانک جملات با هجای از پیش شمرده‌شده** (دستی، ~۵۰ جمله، contentVersion '1') — چون شمارش هجای فارسی از املا ممکن نیست. دشواری = طول جمله. ۱۲ سؤال.
3. **Sequence Logic** (`src/modules/reasoning/games/sequence-logic/` — پوشه استدلال جدید): توالی عددی با الگو (جمعی/ضربی/متناوب/درجه۲) → انتخاب ادامه از ۴ گزینه؛ distractorهای نزدیک. مولد قطعی، پاسخ همیشه معتبر. ۱۲ سؤال.
4. **Pattern Completion** (`.../pattern-completion/`): ماتریس ۳×۳ نمادهای رنگی با خانه خالی و قاعده سطر/ستون (پیشرفت تعداد/رنگ/شکل) → ۴ گزینه. خانواده قواعد ثابت با پاسخ یکتا. ۱۲ سؤال.
